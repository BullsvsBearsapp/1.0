# Wyoming Bounty Bot

A Discord bot for managing bounties and rewards.

## Setup
1. Install Python dependencies:
   ```bash
   pip install -r requirements.txt
   ```
2. Install ngrok:
   - **Mac**: `brew install ngrok`
   - **Windows**: `choco install ngrok`
3. Run the bot:
   ```bash
   python bot.py
   ```
4. In a new terminal, start ngrok:
   ```bash
   ngrok http 8000
   ```
